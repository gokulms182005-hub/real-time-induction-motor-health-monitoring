# Real-Time Induction Motor Health Monitoring & Fault Alert System

## Overview

A simulation prototype for monitoring induction motor health using current, temperature and vibration parameters.

## Objectives

- Monitor motor operating parameters
- Detect abnormal conditions
- Generate fault alerts
- Demonstrate embedded monitoring logic

## Parameters

- Motor Current
- Temperature
- Vibration

## Fault Detection

- Over Current
- Over Temperature
- High Vibration

## System Flow

Sensor Data → Data Processing → Fault Detection → Alert

## Technologies

- Python
- Embedded Systems Concepts
- Sensor Data Processing
- GitHub

## Project Status

**Simulation Prototype / Work in Progress**

The current version uses simulated sensor values. Physical motor and sensor hardware implementation is planned as future work.
